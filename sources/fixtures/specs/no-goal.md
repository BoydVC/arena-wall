# Lamp Notes

## 6. Acceptance tests
1. The lamp turns on when the path is clear.
2. The lamp stays dim when the path is shut.
3. A keeper can read the status from the doorway.

## 7. Arena seat briefs
### types-first
Name the states in the type so a dim lamp and a lit lamp cannot be confused.

### model-first
Write the on and off edges before any UI.

### experience-first
Make the lamp readable from across the room.
