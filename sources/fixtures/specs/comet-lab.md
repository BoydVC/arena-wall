# Comet Lab

## Goal
Give the lab a timer that survives a dropped bench link.

## User story
As an operator, I see this build move only after the spec is whole.

## Acceptance tests
1. The timer keeps its count across a dropped socket.
2. A failed run names the gate that failed.

## Seat briefs
### types-first
Start from the domain types and make illegal states unrepresentable.
### model-first
Start from the lifecycle model and derive the transitions.
### experience-first
Start from the wall demo and the phone layout.
