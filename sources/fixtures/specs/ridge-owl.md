# Ridge Owl

## Goal
Night survey notes for the ridge, shown as a draft that still needs a person.

## User story
As an operator, I see the gold waiting badge before anyone treats the draft as finished.

## Acceptance tests
1. The experience-first seat leads the scoreboard once its tests are clean.
2. The demo gate shows a thumbnail when it is green.
3. The card lands in the draft lane while the human gate is red.

## Seat briefs
### types-first
Start from the draft and merged types so a merge cannot be represented early.
### model-first
Start from the human-ok guard on the merge edge.
### experience-first
Start from the badge, the thumbnail, and the three-up diff.
